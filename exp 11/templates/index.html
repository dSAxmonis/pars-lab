Experiment 11: Linear Discriminant Analysis (LDA) with Testing

Pattern Analysis & Recognition Systems Lab  |  Repository: https://github.com/dSAxmonis/pars-lab

AIM

To implement Linear Discriminant Analysis (LDA) from scratch in Python for an engineering pattern classification application involving testing, derive Fisher's optimal projection vector $\mathbf{w} = \mathbf{S}_W^{-1} (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)$, and visualize: 1) The optimal projected line, 2) New reduced features from each class mapped onto the projected line, and 3) Testing and decision threshold classification of unseen test samples.

Dashed projection segments drop each observation orthogonally onto the line, where the reduced features form distinct separated clusters. The black cross marker on the line designates the decision threshold. The active test sample is depicted as a yellow star with its projection shown as a green diamond.
