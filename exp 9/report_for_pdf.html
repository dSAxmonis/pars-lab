Practical Name

Implementation of Regularization (L1 / Lasso & L2 / Ridge) for Overfitting Prevention and Generalization

Aim

To implement L1 (Lasso) and L2 (Ridge) Regularization techniques from scratch in Python to prevent overfitting in high-capacity non-linear classifiers. The application demonstrates the effect of regularization on model variance by generating and plotting: 1) Non-linear decision boundaries before and after applying regularization, and 2) Quantitative performance comparison curves showing training vs. test generalization across varying regularization penalties (lambda).

Definitions & Core Concepts

The Overfitting Problem (High Variance): When a classifier with excessive capacity (e.g., 6th-order polynomial expansion creating 28 features) is trained on complex data, it fits noise artifacts, yielding 100% training accuracy but severely failing on unseen test samples.

L2 Regularization (Ridge / Weight Decay): Penalizes the sum of squared weight magnitudes (Euclidean norm), shrinking all weights proportionally toward zero and smoothing decision boundary curvature.

L1 Regularization (Lasso / Sparse Feature Selection): Penalizes the sum of absolute weight values (Manhattan norm), forcing non-essential weights strictly to zero and performing automated feature pruning.

Mathematical Formulations

1. High-Order Polynomial Feature Mapping

To enable non-linear decision surfaces, 2D input features (x1, x2) are mapped into a 6th-degree polynomial space φ(x) ∈ ℜ28:

Polynomial Feature Vector:
φ(x1, x2) = [ 1, x1, x2, x12, x1x2, x22, …, x16, …, x26 ]T ∈ ℜ28

2. L2 Regularization (Ridge Regression / Weight Decay)

Penalizes the sum of squared weights, preventing extreme weight values:

L2 Objective Function:
JL2(w, b) = J0(w, b) + [ λ / ( 2·m ) ] × ∑j=1d wj2

Weight Decay Gradient Update:
wj := wj × [ 1 - ( α·λ / m ) ] - α × ( ∂J0 / ∂wj )

Where:
• J0(w, b) is the unregularized Cross-Entropy loss.
• λ ≥ 0 is the regularization strength parameter.
• The shrinkage multiplier [ 1 - ( α·λ / m ) ] < 1 shrinks weights at every gradient step.
• Bias b is not regularized to avoid penalizing base class balance.

3. L1 Regularization (Lasso / Sparse Selection)

Penalizes absolute weight values, inducing structural parameter sparsity:

L1 Objective Function:
JL1(w, b) = J0(w, b) + [ λ / m ] × ∑j=1d |wj|

Subgradient Parameter Update:
wj := wj - α × ( ∂J0 / ∂wj ) - α × ( λ / m ) × sgn(wj)

Where:
• sgn(wj) = +1 if wj > 0, -1 if wj < 0, and 0 if wj = 0.
• Non-contributing polynomial weights are driven exactly to 0.0.

Algorithmic Methodology & Implementation Steps

  1. Generated synthetic non-linear microchip classification dataset with complex non-convex class boundaries.
  2. Constructed a 6th-degree polynomial feature expansion converting 2 input dimensions into a 28-dimensional space.
  3. Implemented unregularized, L1-regularized (Lasso), and L2-regularized (Ridge) gradient descent optimization loops in pure NumPy.
  4. Evaluated training and holdout test set accuracies across varying regularization penalties (λ ∈ [0.0, 0.001, 0.01, 0.1, 1.0, 10.0]).
  5. Deployed interactive Flask dashboard on port 5011 displaying side-by-side decision boundary contours and train-vs-test generalization curves.

Conclusion

Experiment 9 demonstrated the necessity and mechanics of L1 and L2 regularization in controlling model complexity. The results confirmed that unregularized high-degree models overfit training noise with erratic boundaries, while L2 regularization smoothly constrains parameter magnitudes and L1 regularization induces weight sparsity, both successfully optimizing test set generalization.
