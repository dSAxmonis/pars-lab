EXPERIMENT AIM & MATHEMATICAL OBJECTIVE
Experiment Aim To implement a collaborative-based recommender system for any application (Movies Recommender System) from scratch using Flask and pure NumPy without machine learning libraries.
Core Algorithm User-Item Collaborative Filtering: Compute User-User Pearson correlation similarity matrix r(u, v) = Σ((R_u - μ_u)(R_v - μ_v)) / (√Σ(R_u - μ_u)² √Σ(R_v - μ_v)²) across co-rated items. Predict unrated movies using Resnick's mean-centered weighted average of top-K similar peers: &Rcirc;(a, i) = μ_a + Σ(sim(a, v) × (R_{v,i} - μ_v)) / Σ|sim(a, v)|.
Validation Metric Leave-One-Out validation on known active user ratings comparing Actual Ratings vs Predicted Ratings with Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).
