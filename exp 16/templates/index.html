SECTION 1: EXPERIMENT AIM & MATHEMATICAL FORMULATION SUMMARY
Practical Aim: Implement an Item-Based Nearest Neighbor (kNN) Recommender System from first principles in Python (using pure NumPy without scikit-learn or surprise libraries) within a Flask web application for a movies catalog domain. The system computes item-item similarities across historical co-rating patterns, identifies the $k$ most similar neighbor items already rated by a target user, predicts unknown ratings using a weighted sum aggregation formula, and generates a personalized Top-N recommendation list.
1. Adjusted Cosine Similarity Formula: Standard cosine ignores user rating scale biases. Adjusted Cosine offsets each user's rating by their mean rating across all items $\bar{R}_u$:

sim(i, j) = ∑u ∈ Uij (Ru, i − R̄u)(Ru, j − R̄u) / [ √(∑u (Ru, i − R̄u)2) · √(∑u (Ru, j − R̄u)2) ]

where Uij is the co-rating set of users who rated both item i and item j, and R̄u is user u's average rating.
2. k-Nearest Neighbors Rating Prediction: For target user u and unrated candidate movie i, let Sk(i; u) be the set of k items rated by user u with the highest positive item-item similarity sim(i, j) > 0:

R̂u, i = [ ∑j ∈ Sk(i; u) sim(i, j) · Ru, j ] / [ ∑j ∈ Sk(i; u) sim(i, j) ]

Predicted ratings are bounded within the rating scale [1.0, 5.0]. If no positively correlated rated neighbors exist, the system gracefully falls back to the item's catalog mean.
3. Top-N Ranking Criterion: Rank all unrated items ∀ i ∉ Iu in descending order of predicted rating R̂u, i and return the top N highest-scoring movies with full mathematical proof.
