SECTION 1: EXPERIMENT AIM & MATHEMATICAL FORMULATION SUMMARY
Practical Aim: Implement a Weighted Hybrid Recommender System from first principles in Python (using pure NumPy without scikit-learn or surprise libraries) within a Flask web application for a movies catalog domain. The system integrates Content-Based Filtering (cosine similarity over multi-hot genre, director, and plot keyword vectors) with Collaborative Filtering (user-based Pearson correlation matrix across historical peer rating patterns). A tunable trade-off parameter α ∈ [0.0, 1.0] enables dynamic interpolation between content-driven personalization and crowd-based collaborative recommendations.
Mathematical Formulation: 1. Content Similarity: SCB(i, j) = (xi · xj) / (||xi|| · ||xj||) ∈ [0, 1]
2. Collaborative Similarity: w(u, v) = Pearson(ru, rv) = ∑k (ruk - r̄u)(rvk - r̄v) / [√∑(ruk - r̄u)2 √∑(rvk - r̄v)2]
3. Weighted Hybrid Combination: SHybrid(u, i) = α · SCBF(u, i) + (1 - α) · SCF(u, i)
4. Predicted 5-Star Rating: r̂u, i = 1.0 + 4.0 · SHybrid(u, i) ∈ [1.0, 5.0]

Mathematical Sensitivity Interpretation: At α = 1.00, recommendation ranking is determined exclusively by the Cosine Similarity between item feature vectors (genre, director, keywords) and the user's rated profile. As α transitions down to 0.00, the model transitions into User-Based Collaborative Filtering, where user Pearson correlation weights govern ranking. This introduces cross-genre crowd favorites that the user would not discover through content-based filtering alone, effectively bypassing the content "filter bubble".
