Practical Name

Bayesian Classification for Single Feature & Multiple Features Multiple Class Using Flask

Aim

To design, formulate, and deploy an interactive Flask web application to perform pattern classification using the Bayesian framework for both 1) Single Feature Multi-Class models and 2) Multiple Features Multi-Class models. The system fits Gaussian class-conditional likelihoods, calculates posterior class probabilities, and classifies arbitrary user-supplied test samples according to the Maximum A Posteriori (MAP) decision rule.

Definitions & Core Concepts

Bayesian Pattern Classification: A statistical decision-theoretic approach that minimizes classification error by combining prior knowledge of class prevalences with class-conditional likelihood evidence observed from sample features.

Class-Conditional Likelihood: The probability density of observing feature vector x given that the true class is ωk, modeled via univariate or multivariate Normal distributions.

Maximum A Posteriori (MAP) Rule: An optimal classification criterion assigning candidate sample x to the class yielding the highest posterior probability P(ωk | x).

Mathematical Formulations

1. Bayes' Theorem for Pattern Classification

For K mutually exclusive and exhaustive classes ω1, ω2, …, ωK and observed feature vector x:

Bayes' Rule:
P(ωk | x) = [ p(x | ωk) × P(ωk) ] / p(x)

Total Evidence (Normalization Factor):
p(x) = ∑j=1K [ p(x | ωj) × P(ωj) ]

Where:
• P(ωk | x) is the posterior probability that sample x belongs to class ωk.
• p(x | ωk) is the class-conditional probability density function (likelihood).
• P(ωk) is the prior probability of class ωk.
• p(x) is the unconditional marginal feature probability density.

2. Univariate Gaussian Likelihood (Single Feature Multi-Class)

When modeling a single continuous scalar feature x ∈ ℜ:

Univariate Normal Density:
p(x | ωk) = ( 1 / √( 2π σk2 ) ) × exp[ - ( x - μk )2 / ( 2 σk2 ) ]

Where:
• μk = ( 1 / Nk ) ∑ x(i) is the empirical mean of class ωk.
• σk2 = ( 1 / Nk ) ∑ ( x(i) - μk )2 is the empirical variance of class ωk.

3. Multivariate Gaussian Likelihood (Multiple Features Multi-Class)

When modeling a d-dimensional feature vector x ∈ ℜd (e.g., d = 4 for Iris):

Multivariate Normal Density:
p(x | ωk) = ( 1 / [ (2π)d/2 |Σk|1/2 ] ) × exp[ - (1/2) ( x - μk )T Σk-1 ( x - μk ) ]

Where:
• μk ∈ ℜd is the d-dimensional class centroid mean vector.
• Σk ∈ ℜd × d is the class covariance matrix.
• |Σk| is the determinant of the covariance matrix.
• ( x - μk )T Σk-1 ( x - μk ) is the squared Mahalanobis distance.

4. Maximum A Posteriori (MAP) Decision Rule

The optimal decision boundary classifies test vector x by maximizing log-posterior scores:

Optimal Decision Rule:
ω* = argmaxk ∈ {1, …, K} P(ωk | x) = argmaxk ∈ {1, …, K} [ ln p(x | ωk) + ln P(ωk) ]

Algorithmic Methodology & Implementation Steps

  1. Constructed training dataset from Fisher's Iris data spanning 3 distinct flower classes.
  2. Estimated maximum likelihood Gaussian parameters: class scalar means and variances for Single Feature (Petal Length), and mean vectors and covariance matrices for Multiple Features (Sepal Length, Sepal Width, Petal Length, Petal Width).
  3. Formulated univariate and multivariate Gaussian likelihood evaluators with numerical stability safeguards.
  4. Built interactive Flask application on port 5007 accepting test sample inputs, computing real-time posterior probabilities, and rendering decision curves.

Conclusion

Experiment 4 verified the theoretical rigor and practical efficacy of Bayesian pattern classification. By evaluating both Single Feature (univariate Gaussian) and Multiple Feature (multivariate Gaussian with full covariance matrices) models, the application demonstrated how Mahalanobis distance and class covariance geometry govern optimal decision surfaces under the Maximum A Posteriori (MAP) rule, achieving optimal error minimization.
