Practical Name

Text Paragraph Segmentation, Stop Words Removal, Stemming, Lemmatization, and Bayesian Classification Using Flask

Aim

To construct an end-to-end Natural Language Processing (NLP) text processing and classification web pipeline using Flask. The system ingests raw paragraph text, segments it into individual sentences, eliminates non-informative stop words, applies Porter Stemming and WordNet Lemmatization, and classifies test sentences into thematic categories using Multinomial Naive Bayes classification with Laplace smoothing.

Definitions & Core Concepts

Text Segmentation & Tokenization: The process of decomposing unstructured continuous text into discrete grammatical units (sentences) and lexical units (word tokens).

Stop-Word Removal: Filtering out high-frequency grammatical words (articles, prepositions, auxiliary verbs) that carry negligible domain-specific topical discrimination.

Morphological Normalization (Stemming vs. Lemmatization): Stemming uses heuristic rule-based suffix truncation (Porter stemmer), while Lemmatization utilizes full lexical vocabulary lookup and Part-of-Speech analysis (WordNet lemmatizer) to return canonical dictionary base forms.

Multinomial Naive Bayes: A probabilistic model for text classification that models document generation as a bag-of-words drawn from a multinomial word distribution.

Mathematical Formulations

1. Multinomial Naive Bayes Word Likelihood (with Laplace Smoothing)

The probability of observing word token wi in class Ck is calculated using add-1 (Laplace) smoothing to prevent zero-probability bottlenecks:

Laplace-Smoothed Word Likelihood:
P(wi | Ck) = ( Nki + α ) / ( Nk + α·|V| )

Where:
• Nki is the total occurrence count of word wi in training documents belonging to class Ck.
• Nk = ∑j=1|V| Nkj is the total count of all words in class Ck.
• |V| is the size of the total shared vocabulary across all classes.
• α = 1.0 is the Laplace smoothing parameter ensuring P(wi | Ck) > 0 for unseen words.

2. Document Class Log-Posterior Formulation

Under the naive conditional independence assumption, the log-posterior probability of class Ck given document d is:

Log-Posterior Classification Score:
ln P(Ck | d) ∝ ln P(Ck) + ∑i=1|V| fi × ln P(wi | Ck)

Where:
• P(Ck) = |Dk| / |D| is the prior probability of class Ck.
• fi is the frequency count of word wi in test document d.
• Optimal class assignment: C* = argmaxk [ ln P(Ck | d) ].

3. Morphological Stemming vs. Lemmatization Rules

Porter Stemming Transformation:
w → Stem(w)     (e.g., "studying", "studies", "studied" → "studi")

WordNet Lemmatization Transformation:
w, pos → Lemma(w, pos)     (e.g., "better" → "good" [adj]; "running" → "run" [verb])

Algorithmic Methodology & Implementation Steps

  1. Built regular expression tokenizer splitting input paragraph into clean individual sentences.
  2. Implemented standard stop-words filter removing ubiquitous functional tokens from the text.
  3. Integrated Porter Stemmer and WordNet Lemmatizer generating side-by-side morphological normalization comparisons.
  4. Constructed vocabulary vectorizer and trained Multinomial Naive Bayes model on benchmark categories (AI/Tech vs Sports).
  5. Deployed interactive Flask dashboard on port 5008 allowing users to submit custom paragraphs, visualize step-by-step transformations, and inspect sentence classification.
