EXPERIMENT AIM & SCOPE
Aim: To implement a comprehensive Content-Based Recommender System from scratch using Python (NumPy) and Flask for a real-world movie streaming application catalog. The system performs:
  • Feature extraction and sublinear TF-IDF term weighting across movie genres, directors, cast members, and plot keywords.
  • Row-wise L2 Euclidean normalization and high-dimensional pairwise Cosine Similarity Matrix computation ($M \times M$).
  • Interactive Item-to-Item content recommendation with feature attribution (shared genres/tags).
  • Personalized User Content Profile modeling ($\mathbf{p}_u$) and rating prediction ($\hat{r}_{uj}$) for unseen movies across 8 distinct user personas.
  • Full internal visualization via 4-panel diagnostic plots (Heatmap, Top-N bar charts, TF-IDF weights, Rating sparsity).

Content-Based Personalization Engine Workflow:
  1. Aggregates user rating weights: $w_i = (r_{ui} - \bar{r}_u + 1.0)$.
  2. Constructs dense User Profile Vector $\mathbf{p}_u = \sum w_i \mathbf{x}_i^*$.
  3. Normalizes $\mathbf{p}_u^* = \mathbf{p}_u / \|\mathbf{p}_u\|_2$ in $\mathbb{R}^K$ (where vocabulary dimension $K = {{ vocab_size }}$).
  4. Evaluates cosine affinity $\hat{y}_{uj} = \mathbf{p}_u^* \cdot \mathbf{x}_j^*$ for unrated movies.
  5. Ranks candidates and projects predicted rating $\hat{r}_{uj} \in [1.0, 5.0]$.

SECTION 6: MATHEMATICAL FORMULATIONS (IMPLEMENTED FROM SCRATCH IN NUMPY)
Algorithm Component Mathematical Formula & Vector Space Definition
1. Document Bag of Features $D_i = \{\text{genres}_i\} \cup \{\text{director}_i\} \cup \{\text{cast}_i\} \cup \{\text{keywords}_i\}$, with unique vocabulary $V = \{t_1, \dots, t_K\}$.
2. Term Frequency (TF) $\text{TF}(t_k, D_i) = \frac{\text{count}(t_k, D_i)}{\sum_{t \in D_i} \text{count}(t, D_i)} = \frac{f_{ik}}{|D_i|}$
3. Smooth Inverse Document Frequency (IDF) $\text{IDF}(t_k) = \ln\left( \frac{1 + M}{1 + \text{DF}(t_k)} \right) + 1.0$, where $\text{DF}(t_k) = \sum_{i=1}^M \mathbb{I}(f_{ik} > 0)$.
4. TF-IDF Representation & L2 Normalization $X_{ik} = \text{TF}(t_k, D_i) \times \text{IDF}(t_k)$,   normalized to unit sphere: $\mathbf{x}_i^* = \frac{\mathbf{x}_i}{\|\mathbf{x}_i\|_2} = \frac{\mathbf{x}_i}{\sqrt{\sum_{k=1}^K X_{ik}^2}}$.
5. Pairwise Cosine Similarity Matrix $S_{ij} = \cos(\mathbf{x}_i, \mathbf{x}_j) = \frac{\mathbf{x}_i \cdot \mathbf{x}_j}{\|\mathbf{x}_i\|_2 \|\mathbf{x}_j\|_2} = \mathbf{x}_i^* \cdot \mathbf{x}_j^* \implies \mathbf{S} = \mathbf{X}^* (\mathbf{X}^*)^T$.
6. User Content Profile Modeling $\mathbf{p}_u = \sum_{i \in \text{Rated}(u)} (r_{ui} - \bar{r}_u + 1.0) \mathbf{x}_i^*$,   with unit profile $\mathbf{p}_u^* = \frac{\mathbf{p}_u}{\|\mathbf{p}_u\|_2}$.
7. Rating Prediction & Ranking $\hat{r}_{uj} = \text{clip}\left(\bar{r}_u + 2.4 (\mathbf{p}_u^* \cdot \mathbf{x}_j^* - 0.2), 1.0, 5.0\right)$,   ranked descending for unrated items.
