EXPERIMENT AIM & ALGORITHMIC PRINCIPLES
AIM: To implement a User-based Nearest Neighbor (kNN) Recommender System from scratch in Python using pure NumPy (without scikit-learn or Surprise), deploy an interactive web portal using Flask with a 20-movie catalog across diverse genres, compute pairwise user similarity via Pearson Correlation / Cosine metrics, select $k$ nearest neighbors, predict ratings using the mean-centered deviation formula:

$$\hat{r}_{a,j} = \bar{r}_a + \frac{\sum_{u \in N_{k}(a)} s(a, u) \cdot (r_{u,j} - \bar{r}_u)}{\sum_{u \in N_{k}(a)} |s(a, u)|}$$

and visually inspect internal similarity matrices, neighbor selections, and predicted rating distributions via Matplotlib.
