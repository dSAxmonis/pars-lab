Practical Name

Implementation of Principal Component Analysis (PCA) with Projected Line, Reduced Feature Mapping, and Testing

Aim

To implement Principal Component Analysis (PCA) from scratch in pure NumPy without using pre-built machine learning libraries. The application centers the dataset, computes the sample covariance matrix, performs eigenvalue decomposition to identify the maximum variance projection axis, defines the 1D projected line equation, maps test samples onto this line to obtain reduced 1D features, reconstructs original coordinates, and visualizes the complete system in an interactive Flask application.

Definitions & Core Concepts

Principal Component Analysis (PCA): An unsupervised, orthogonal linear transformation technique that reduces dimensionality by projecting data onto orthogonal axes that maximize variance while minimizing reconstruction error.

Sample Covariance Matrix Σ: Quantifies pairwise linear relationships and joint variability across feature dimensions around the sample mean centroid.

Eigenvalue Decomposition: Factorizes the covariance matrix Σ into eigenvectors (principal projection directions) and eigenvalues (amount of variance explained along each axis).

Mathematical Formulations

1. Mean Centering & Sample Covariance Matrix

Data matrix X ∈ ℜn × d is centered around sample mean vector μ:

Empirical Centroid:
μ = ( 1 / n ) × ∑i=1n x(i)

Zero-Mean Centered Matrix:
X̃ = X - 1 μT

Sample Covariance Matrix Formulation:
Σ = ( 1 / ( n - 1 ) ) × X̃T X̃ ∈ ℜd × d

Where:
• n is the total number of training observations.
• d is the feature dimensionality (d = 2 for bivariate visual demo).
• Σ is symmetric and positive semi-definite.

2. Eigenvalue Decomposition & Variance Maximization

Solving the characteristic equation identifies orthogonal principal component directions:

Eigen-System Equation:
Σ vk = λk vk,     where λ1 ≥ λ2 ≥ … ≥ λd ≥ 0

Explained Variance Ratio for 1st Principal Component:
EVR1 = λ1 / ∑j=1d λj

Where:
• v1 is the first principal eigenvector (unit direction vector of maximum variance).
• λ1 is the dominant eigenvalue representing empirical variance along v1.

3. 1D Projected Principal Axis (Line Equation)

The 1st principal component defines a straight line in the original feature space passing through centroid μ:

Parametric Projected Line Equation:
Line(t) = μ + t × v1,     t ∈ ℜ

4. 1D Feature Mapping & Reconstruction of Test Samples

For an arbitrary test observation xtest ∈ ℜd:

Reduced 1D Feature Coordinate (Scalar Score):
ztest = ( xtest - μ ) · v1 = ( xtest - μ )T v1 ∈ ℜ

Reconstructed Coordinate in Original Space:
x̂test = μ + ztest × v1 ∈ ℜd

Orthogonal Reconstruction Error (Residual):
E = || xtest - x̂test ||2 = √( ∑j=1d ( xtest,j - x̂test,j )2 )

Algorithmic Methodology & Implementation Steps

  1. Synthesized benchmark bivariate feature dataset exhibiting correlated variance.
  2. Computed sample empirical mean vector and zero-mean centered data matrix.
  3. Calculated the covariance matrix and extracted principal eigenvalues and eigenvectors using pure NumPy.
  4. Derived parametric line equations for the 1st principal component axis.
  5. Implemented real-time 1D projection and reconstruction mapping for arbitrary test coordinates.
  6. Deployed interactive Flask dashboard on port 5001 showing projection plots, orthogonal residual drops, and variance ratios.
