Experiment 10: Principal Component Analysis (PCA) with Testing

Pattern Analysis & Recognition Systems Lab  |  Repository: https://github.com/dSAxmonis/pars-lab

AIM

To implement Principal Component Analysis (PCA) from scratch in Python for an engineering pattern analysis application involving testing, compute the maximum variance projection vector $\mathbf{v}_1$, and visualize: 1) The 1st principal component projected line, 2) New reduced 1D features mapped directly onto the projected line, and 3) Testing and orthogonal reconstruction of unseen test samples.
