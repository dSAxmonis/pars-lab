EXPERIMENT AIM & MATHEMATICAL OBJECTIVES
Aim / Objective: To implement an Item-Based k-Nearest Neighbor (kNN) Recommender System from scratch in Python using pure NumPy (without any black-box libraries like scikit-learn or Surprise) for implicit/binary feedback (Seen = 1, Not-Seen = 0) within a Flask web application. The experiment derives pairwise Jaccard similarity coefficients between item columns, establishes neighborhood matrices, predicts recommendation relevance for unobserved items, provides transparent recommendation reasons, and visualizes matrix sparsity and convergence diagnostics.
Domain Application: Movies Recommender System — 20 Curated Landmark Films across 7 Genres (Action, Comedy, Drama, Sci-Fi, Horror, Romance, Thriller) evaluated by an 8-user cinephile community.
Mathematical Formulation: Jaccard Item-Item Similarity: J(i, j) = |U_i ∩ U_j| / |U_i ∪ U_j| = (b_i · b_j) / (∑b_i + ∑b_j - b_i · b_j)
Item-Based kNN Ranking Score: Score(c) = (1 / |k-NN(c; S)|) × ∑_{s ∈ k-NN(c; S)} J(c, s), where S is the user's seen set and c ∉ S.
