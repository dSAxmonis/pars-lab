EXPERIMENT AIM & ALGORITHMIC FOUNDATION
Aim: To implement an Item-Based Nearest Neighbor (kNN) Recommender System from scratch in Python using Adjusted Cosine Similarity for a comprehensive Movie Recommendation portal. The system computes user-mean centered item affinities, contrasts Adjusted Cosine against Raw Cosine Similarity, predicts unrated film scores via similarity-weighted neighborhood aggregation, and generates personalized Top-N recommendations.

Core Formulation (Sarwar et al., 2001):
sim_adj(i, j) = ∑u ∈ Ui,j (Ru,i - R̄u)(Ru,j - R̄u)  /  [ √(∑ (Ru,i - R̄u)2) × √(∑ (Ru,j - R̄u)2) ]
Where Ui,j represents the set of users who co-rated items i and j, and R̄u denotes the overall mean rating of user u across all their evaluated items.

SECTION 7: THEORETICAL COMPARISON OF SIMILARITY METRICS IN COLLABORATIVE FILTERING
Similarity Measure Mathematical Expression User Rating Bias Treatment Recommender System Suitability
Standard (Raw) Cosine sim(i,j) = ∑ RuiRuj / [ √∑ Rui2 √∑ Ruj2 ] Ignores user bias. Treats missing ratings as 0, which introduces positive bias distortion. Poor for Item-based CF (Inflates similarity values to ~0.90 even for conflicting genres).
Pearson Correlation sim(i,j) = ∑ (Rui-R̄i)(Ruj-R̄j) / [ √∑(Rui-R̄i)2 √∑(Ruj-R̄j)2 ] Subtracts item mean (R̄i), failing to account for user leniency differences across users. Moderate (Well suited for user-based CF, sub-optimal for item-based CF).
Adjusted Cosine Similarity sim(i,j) = ∑ (Rui-R̄u)(Ruj-R̄u) / [ √∑(Rui-R̄u)2 √∑(Ruj-R̄u)2 ] Subtracts user mean (R̄u) from co-rated items, isolating pure affinity from personal bias. Optimal Benchmark (Industry standard for item-based collaborative filtering).
