Practical Name

Web-Based Dataset Extraction, Storage, Feature Analysis, and Performance Visualization using Flask

Aim

To develop an interactive Flask web application to programmatically extract and store the two datasets studied in Experiment 1 (CIFAR-10 image dataset and Iris tabular dataset), persist them locally in structured formats, compute and display comprehensive descriptive feature statistics, and generate baseline classification performance evaluation plots.

Definitions & Core Concepts

Automated Ingestion & Multimodal Persistence: Raw sensory and structured data are fetched into memory, decoded, and persisted locally to eliminate redundant network bandwidth. High-dimensional visual data is structured into class-hierarchical directories, while tabular relations are serialized into comma-separated value (CSV) formats.

Descriptive Statistical Profiling: Features are quantitatively analyzed through measures of central tendency (mean, median), dispersion (variance, standard deviation, interquartile range), and boundary limits (min, max) to detect outliers, class skewness, and scaling disparities.

Supervised Performance Evaluation: Quantifies the ability of predictive models to generalize decision boundaries across unseen samples using contingency matrices (confusion matrices) and derived harmonic metrics.

Mathematical Formulations

1. Classification Performance Metrics (Confusion Matrix Formulation)

Given binary contingency outcomes where TP = True Positives, TN = True Negatives, FP = False Positives, and FN = False Negatives:

Classification Accuracy:
Accuracy = ( TP + TN ) / ( TP + TN + FP + FN )

Precision (Positive Predictive Value):
Precision = TP / ( TP + FP )

Recall (Sensitivity / True Positive Rate):
Recall = TP / ( TP + FN )

F1-Score (Harmonic Mean):
F1 = 2 × ( Precision × Recall ) / ( Precision + Recall ) = 2·TP / ( 2·TP + FP + FN )

Where:
• TP = Positive instances correctly classified as positive.
• TN = Negative instances correctly classified as negative.
• FP = Negative instances incorrectly classified as positive (Type I error).
• FN = Positive instances incorrectly classified as negative (Type II error).

2. Multi-Class Macro-Averaging

For K-class evaluation, macro-averaged metrics aggregate unweighted performance across all individual classes:

Macro-Averaged F1-Score:
Macro-F1 = ( 1 / K ) × ∑k=1K F1k

Where:
• K is the number of mutually exclusive classes (K = 10 for CIFAR-10; K = 3 for Iris).
• F1k is the binary F1-score evaluated treating class k as positive and all other classes as negative.

3. Continuous Feature Standardization & Normalization

Feature scaling transforms heterogeneous dimensions onto commensurate numerical intervals:

Min-Max Normalization:
xnorm = ( x - xmin ) / ( xmax - xmin ) ∈ [0, 1]

Z-Score Standardization:
z = ( x - μ ) / σ

Where:
• x is the raw scalar observation.
• xmin, xmax are the minimum and maximum observed attribute bounds.
• μ is the empirical feature mean and σ is the empirical standard deviation.

Algorithmic Methodology & Implementation Steps

  1. Implemented automated dataset ingestion pipeline fetching raw CIFAR-10 image samples and Fisher's Iris tabular records.
  2. Serialized datasets locally into structured directory hierarchies (images sorted by class folders) and standard CSV files.
  3. Computed descriptive statistical profiles across all continuous dimensions (mean, standard deviation, quartiles, and range bounds).
  4. Evaluated classification performance using confusion matrices, precision, recall, and macro-F1 benchmarks.
  5. Deployed interactive Flask dashboard on port 5005 displaying dataset statistics, sample browsers, and dynamic performance plots.
