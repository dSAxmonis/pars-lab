EXPERIMENT AIM & MATHEMATICAL OBJECTIVE:
To implement Matrix Factorization from scratch using Stochastic Gradient Descent (SGD) in pure NumPy without external recommender libraries (such as scikit-learn or Surprise). The algorithm factorizes an incomplete user-item rating matrix R ≈ P × QT into lower-rank user latent vectors P ∈ ℝm × k and item latent vectors Q ∈ ℝn × k. The model is trained iteratively for at least 3 epochs minimizing regularized Mean Squared Error (MSE), tracking monotonic loss reduction, filling in previously unknown/unrated ratings, and generating top-N personalized movie recommendations.
