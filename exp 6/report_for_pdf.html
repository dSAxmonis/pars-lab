Practical Name

Bayesian Risk Minimization for Three Classes and Three Actions Using Flask

Aim

To formulate, implement, and deploy an interactive Flask web application to perform Bayesian Risk Minimization for a pattern classification problem consisting of at least three classes (ω1, ω2, ω3) and three permissible operational actions (α1, α2, α3). Given a user-defined loss matrix, the system calculates conditional risk for each action, triggers the minimum-risk action, and reflects the decision and risk landscape dynamically in the web interface.

Definitions & Core Concepts

Bayesian Decision Theory & Risk: In real-world decision making, the costs of different errors are rarely equal (e.g., misdiagnosing a malignant disease is far more catastrophic than a false positive). Bayesian Risk Minimization incorporates asymmetric loss matrices to choose actions that minimize expected cost rather than merely misclassification rate.

Loss Matrix Λ: A formal matrix where λ(αi | ωj) defines the quantitative penalty of taking action αi when the true state of nature is ωj.

Conditional Risk R(αi | x): The expected loss incurred by deciding on action αi given feature observation x, calculated by weighting loss penalties by posterior class probabilities.

Mathematical Formulations

1. Conditional Risk (Expected Loss) Formulation

For an observation x with posterior class probabilities P(ωj | x), the conditional risk for action αi is:

Conditional Risk Formula:
R(αi | x) = ∑j=13 λ(αi | ωj) × P(ωj | x)

Expanded Formulation for 3 Classes:
R(αi | x) = [ λ(αi | ω1)·P(ω1 | x) ] + [ λ(αi | ω2)·P(ω2 | x) ] + [ λ(αi | ω3)·P(ω3 | x) ]

Where:
• αi ∈ { α1, α2, α3 } represents the candidate action.
• ωj ∈ { ω1, ω2, ω3 } represents the true underlying state of nature.
• λ(αi | ωj) is the loss entry in row i, column j of the loss matrix.
• P(ωj | x) is the posterior probability of class ωj, satisfying ∑j=13 P(ωj | x) = 1.0.

2. Loss Matrix Specification (Λ)

The asymmetric 3×3 loss matrix penalizes misclassifications according to operational severity:

Loss Matrix Structure:
Λ =
[ [ λ(α1|ω1)=0, λ(α1|ω2)=10, λ(α1|ω3)=50 ],
  [ λ(α2|ω1)=5, λ(α2|ω2)=0, λ(α2|ω3)=20 ],
  [ λ(α3|ω1)=30, λ(α3|ω2)=15, λ(α3|ω3)=0 ] ]

Where:
• Diagonal elements λ(αi | ωi) = 0 represent zero penalty for correct actions.
• Off-diagonal elements represent asymmetric penalties (e.g., severe cost 50 for choosing action 1 when true class is 3).

3. Minimum Risk Decision Rule

The optimal Bayesian decision selects the action that achieves the minimum conditional risk:

Optimal Action Selection:
α* = argmini ∈ {1, 2, 3} R(αi | x)

Algorithmic Methodology & Implementation Steps

  1. Defined a 3-class, 3-action clinical / operational decision domain with verifiable asymmetric loss penalties.
  2. Implemented posterior probability ingestion accepting observation vectors and normalizing evidence.
  3. Coded pure NumPy matrix multiplication evaluating conditional risk vectors R across all candidate actions.
  4. Programmed threshold logic triggering the optimal minimum-risk action and highlighting affected UI states.
  5. Deployed interactive Flask dashboard on port 5002 with editable loss matrices, probability sliders, and risk comparison plots.

Conclusion

Experiment 6 demonstrated the critical importance of Bayesian Risk Minimization in asymmetric decision environments. By incorporating non-uniform loss matrices, the application illustrated how an action associated with a lower posterior probability can be rationally chosen if alternative choices carry catastrophic error penalties, successfully operationalizing the principle of minimum expected risk.
